01 / WEB

留在网页里阅读

双语、仅中文、原文，随时切换。用中文按意思查找英文段落，结果指向原文；也可选择打开网页后自动翻译。

02 / PDF

积累每一页成果

默认保存页码、原文与译文，重开文件继续读。支持整页或单段重译、本机 OCR 补读，以及阅读包导出与导入；也可选择仅本次阅读。

03 / INPUT

写完，直接翻译

先点击插件图标，再在网页搜索框快速连按三次空格，直接替换内容。快捷键可翻译选区并恢复原文；地址栏输入 zt 后按空格，也可进入输入翻译。不会自动提交表单。

选择清楚，使用安心

翻译方式，由你决定。

浏览器本地翻译

设备支持时在本机生成译文，首次可能下载语言包。无需插件账号。

使用自己的 API

支持 OpenAI-compatible 服务。启用前显示接收地址和发送范围，由你确认有权发送；文字发送到你配置的服务，按服务商计费。设置中可撤回确认。

知道当前支持什么

网页与 PDF 主要为英文译简体中文；输入翻译可选多种目标语言。图片文字识别目前支持英文、德文。复杂 PDF 请对照原页核对。

阅读方式与保存选择

需要时自动，保存前有选择。

默认手动读取网页、自动保存 PDF。自动翻译和临时阅读都由你选择。

04 / AUTO

打开网页自动翻译

开关默认关闭。启用并授权后，新打开或刷新的普通网页可以在后台翻译，关闭侧栏也能运行；沿用当前翻译服务，API 可能计费。关闭开关停止任务，保留已完成译文；PDF 使用独立阅读页。

05 / SESSION

PDF 仅本次阅读

打开文件或导入阅读包前选择。原 PDF、原文和译文只在当前阅读窗口保留，关闭后丢失，不写入文档记录或译文缓存。临时模式使用 API 时仍会发送待译文字；不会删除已有记录和外部备份。

06 / DATA

清楚保存，也清楚删除

删除文档时清理原 PDF、阅读成果及关联译文缓存；无法归属的历史缓存会在确认中提示。其他文档长期记录保留，导出备份和服务商中的数据需另行处理。

FAQ

开始前，了解这几件事。

需要注册账号吗？

插件本身不需要账号。浏览器本地翻译取决于设备支持；使用自己的 API 时，需要相应服务的配置或密钥。GitHub 公开反馈需要 GitHub 账号。

阅读数据保存在哪里？

默认将译文缓存和 PDF 阅读成果保存在当前浏览器，不做云端同步。文档记录不自动过期，但卸载扩展或清除浏览器数据会删除记录。仅本次阅读不写入文档记录或译文缓存，也不会删除已有记录；请按需导出备份。

能导出一本普通中文版 PDF 吗？

目前导出阅读包 ZIP，包含完整原 PDF、已保存原文与译文、排版数据，可导入后继续阅读；不会导出 API Key。阅读包未加密，只能处理有权使用的资料，公开传播须取得相应授权。删除扩展内记录不会删除备份。普通中文版 PDF 导出尚未提供，OCR 也可能漏字。

这个网站会读取我的文档吗？

这个介绍页不访问扩展数据、文档或剪贴板，也不内嵌统计或第三方表单。反馈链接会打开对应服务；只有你选择提交的内容才会进入反馈渠道。

API 与资料处理

发送什么，由谁接收？

什么时候需要确认 API 发送？

首次配置、旧版未确认配置、更换接收地址，或从手动扩大到后台自动翻译时，需要查看告知并确认有权发送。同一地址与范围可保留确认，设置中可撤回；撤回后关闭自动 API 翻译并阻止新的 API 请求。取消不会保存本次配置，也不会发送翻译内容。

API 会收到哪些文字？

网页翻译发送提取的文字，输入翻译发送待译文字；开启自动翻译后，新网页也可能在后台发送。PDF 发送待译段落，并附带当前页最多 20,000 字符、上一页结尾和下一页开头各最多 1,200 字符的上下文；不把原 PDF 文件作为翻译附件上传。费用与接收方的数据留存按所选服务商规则执行。

API Key 会进入文档或阅读包吗？

Key 保存在当前浏览器的扩展本地设置中，不同步，也不进入 PDF 阅读记录、译文缓存或导出阅读包。它会随 API 请求用于向你配置的服务认证。本地存储未使用系统加密保险库，共享设备或浏览器配置备份可能暴露 Key；可清除本机 Key，服务商处的撤销需另行操作。

保密或无法确认授权的资料怎么办？

涉及国家秘密的资料不得使用本扩展联网翻译。企业保密资料、个人信息或受限制文档，先核实处理与发送权限及单位规定。无法确认时取消 API 操作，咨询所属单位的保密或合规负责人。扩展不能鉴定国家秘密，用户确认也不代表资料已通过合规审查。
