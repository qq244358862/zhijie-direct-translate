开始使用

装好后，打开一篇文章。

当前为桌面浏览器开发版。安装包发布后，将在这里提供下载入口。

  1. 获取安装包

    解压安装资料包，找到直接包含 manifest.json 的扩展文件夹。

  2. 加载到浏览器

    打开扩展管理页，启用开发者模式，选择“加载已解压的扩展程序”。Chrome：chrome://extensions；Edge：edge://extensions。

  3. 点击图标，开始阅读

    固定工具栏图标。打开英文文章，点击图标，再读取页面并翻译。更新扩展后重新加载，并刷新网页。

FAQ

开始前，了解这几件事。

需要注册账号吗？

插件本身不需要账号。浏览器本地翻译取决于设备支持；使用自己的 API 时，需要相应服务的配置或密钥。GitHub 公开反馈需要 GitHub 账号。

阅读数据保存在哪里？

译文缓存和 PDF 阅读成果保存在当前浏览器。文档记录不自动过期，但卸载扩展或清除浏览器数据仍会删除记录，请导出阅读包备份。

能导出一本普通中文版 PDF 吗？

目前导出阅读包 ZIP，包含原 PDF、已保存译文和排版数据，可导入后继续阅读。普通中文版 PDF 导出尚未提供；图片识别也不能保证读到页面上所有文字。

这个网站会读取我的文档吗？

这个介绍页不访问扩展数据、文档或剪贴板，也不内嵌统计或第三方表单。反馈链接会打开对应服务；只有你选择提交的内容才会进入反馈渠道。
