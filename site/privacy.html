直接翻译隐私政策

生效及更新日期：2026-10-04 · 适用版本：0.6.8
适用产品：直接翻译 / Direct Translate 浏览器扩展及产品官网
运营者：TIANMENG（个人运营）
隐私与支持联系：hello@tianmengdesign.com

本机保存与联网发送是不同操作。选择自己的 API 时，翻译文字会直接发送给你指定的服务；“仅本次阅读”不阻止 API 发送。阅读包导出含完整原 PDF，且未加密。请仅处理有权使用的资料。

1. 功能、目的与有限使用

本扩展用于网页与 PDF 双语阅读、用户触发的输入翻译、段落查找及本机阅读成果保存。无需注册扩展账号，没有开发者运营的翻译中转、遥测或广告服务。

本扩展对通过 Chrome 扩展接口取得的用户数据的使用遵循 Chrome Web Store 用户数据政策的有限使用要求（Limited Use）：仅用于已说明的阅读、翻译、查找和保存功能；不出售用户数据，不为广告、数据交易、信用评级或贷款使用或转移数据，不为无关用途收集浏览活动。运营者不接收或人工查看用户的扩展内容。用户自愿提交的具体支持资料仅用于处理对应反馈。

2. 处理哪些资料

  • 用户选择的网页正文、选区、输入文字、PDF 原件、识别文字、原文和译文；内容可能含个人身份、通信、健康或财务信息，扩展不能可靠自动剔除。
  • 功能所需的当前页面 URL、标题、段落和翻译状态，用于读取、定位、恢复和防止旧结果覆盖新页面，不收集全量浏览历史。
  • 翻译服务、语言、API 端点、模型、Key、授权和发送确认，以及阅读位置、文字坐标、翻译缓存和语义模型资料。

输入翻译只处理用户触发的文字，排除密码框，不记录全部按键或鼠标轨迹，不自动提交表单。扩展没有 GPS 定位、支付或账户注册功能。

3. 本机处理与外部服务

受支持的浏览器本地翻译、OCR 和语义推理在设备上处理文字。浏览器可能下载本地翻译资源；语义模型从 Hugging Face 及其资源域名下载，提供方可能取得 IP 等常规连接资料。网页段落和查询用于本机推理，执行脚本和 Wasm 随扩展提供。

使用 API 时，目标文字及认证所需 Key 直接发送给用户指定端点，运营者不接收中转副本。PDF 请求发送待译段落，并可附带当前页最多约 20,000 字符及相邻页各最多约 1,200 字符的上下文，不把整个原 PDF 作为翻译附件上传。自动网页翻译默认关闭；启用、授权并完成所需确认后，可在侧栏关闭时处理新打开或刷新的网页。

API 服务可能收费、保留请求或在其他国家处理数据，适用其自己的条款。远程 API 要求 HTTPS；同机 loopback 服务可使用 HTTP。在线 PDF 从用户指定的 HTTP(S) 来源下载，省略请求凭据和来源引用，不携带翻译 Key；HTTP 来源及其重定向不具备 HTTPS 的传输保护。请优先使用可信 HTTPS 来源，或下载后打开本地文件。

4. 保存、期限和安全

API 配置保存在扩展的 chrome.storage.local，PDF 阅读资料和翻译缓存保存在扩展的 IndexedDB，不使用浏览器同步。版本 0.6.8 对 API 配置、PDF 原件、文件名、原文、译文和翻译缓存使用 AES-GCM 自动加密，无需设置密码或重启解锁。随机密钥作为不可通过 Web Crypto 导出的 CryptoKey 保存在同一扩展的浏览器存储中。这不是系统或硬件保险库；完整浏览器资料被复制或设备被控制时仍可能被解密。摘要 ID、页码、版本、缓存时间和密文大小等索引可观察。

PDF 原件、识别文字、译文与位置默认长期保存，直至用户删除或清除扩展资料。译文缓存按 30 天有效期、最多 1,000 条在读取或写入时检查清理，不保證到期即刻擦除磁盘。自动翻译临时页面状态使用会话存储；地址栏文字交接在读取后删除，并在后续访问时检查短期限期。旧资料逐条校验加密副本后替换，不能保证擦除数据库旧页或旧备份。

密钥丢失或损坏时，运营者无法恢复资料；扩展不会自动创建新密钥覆盖旧密文。重新安装会清除本机配置和阅读资料，之后可导入自己的原 PDF 或阅读备份。请保留自己的原件或备份。

5. 用户选择、删除和导出

在打开 PDF 或导入阅读包前，可选择“仅本次阅读”：文件、原文和译文只在该窗口内保留，关闭后丢失，不写入阅读记录或译文缓存；已有记录不删除，仍沿用当前 API 或本地翻译方式。

设置中可清除 API Key、译文缓存和语义模型；删除文档会删除原件、记录、页面成果及关联缓存。无法归属的旧版缓存按明确提示处理。清除本机 Key 不会撤销服务商 Key；已发请求不能收回，服务方副本需按其规则另行处理。

用户主动导出的阅读包 ZIP 未加密，包含完整原 PDF、原文、已保存译文和排版数据，不含 API Key 或本机加密密钥。删除扩展记录不会删除导出包、设备备份或第三方副本，须自行分别删除。复制或分享资料需要相应授权。

6. API 确认与使用限制

使用 API 前显示接收地址和发送范围；首次配置、更换接收方或扩大到自动翻译需要相应确认。设置中可撤回，阻止新的请求，不能保证取消服务方已收到的在途请求。只处理有权使用的资料，不得向未经许可的第三方发送国家秘密或受限制保密资料。无法确认授权时取消并咨询所属单位。机器翻译和 OCR 可能有误，重要内容请核对原文。

7. 官网、反馈和其他服务

官网为 GitHub Pages 静态网站，仅在浏览器本地记住界面语言，不读取扩展 Key、文档或剪贴板，没有运营者嵌入的分析追踪脚本、外部字体或第三方表单。托管方可能处理 IP 等访问资料。

GitHub Issues 反馈公开；邮件反馈由收件方及邮件服务处理。请勿提交 Key、密码、私人 PDF 或保密资料。如需协助，仅提供必要且已遮挡敏感信息的内容。浏览器、托管、模型、API、邮件和反馈平台有自己的隐私条款；扩展运营者不能代替这些第三方保证删除。

8. 联系和变更

隐私疑问或请求删除你主动发送的支持资料，请联系上述邮箱。运营者不能远程读取、恢复或删除你设备上的阅读资料，需在扩展或浏览器中自行操作。处理方式实质变化时更新本政策、商店披露和所需界面告知。本文说明资料处理方式，不免除适用法律义务。

直接翻譯隱私政策

生效及更新：2026-10-04 · 版本 0.6.8
產品：直接翻譯 / Direct Translate 擴充功能及產品官網
營運者：TIANMENG（個人營運）
聯絡：hello@tianmengdesign.com

本機儲存與連網傳送是不同操作。使用自己的 API 時，文字直接傳給你指定的服務；「僅本次閱讀」不阻止 API 傳送。匯出的閱讀包含完整原 PDF，且未加密。僅處理有權使用的資料。

1. 目的與有限使用

擴充功能提供網頁及 PDF 雙語閱讀、使用者觸發的輸入翻譯、段落查找及本機成果儲存，無須註冊擴充功能帳號。沒有營運者提供的翻譯中轉、遙測或廣告服務。透過 Chrome 擴充功能介面取得的使用者資料，依 Chrome Web Store 的 Limited Use 要求，僅用於已說明的閱讀、翻譯、查找及儲存功能。不出售資料，不用於廣告、資料交易、信用評級或貸款，不為無關目的收集瀏覽活動。營運者不接收或人工查看擴充功能內容；使用者自願提供的特定支援資料僅用於處理該回饋。

2. 資料與傳送

處理使用者選擇的網頁正文、選取範圍、輸入文字、PDF、識別原文及譯文，功能所需的目前網址、標題、段落、狀態，以及服務、語言、API 端點／模型／Key、權限、確認、閱讀位置、座標、快取及模型資料。內容可能含身分、通訊、健康或財務資訊，無法可靠自動移除。不收集完整瀏覽歷史，不記錄所有按鍵或滑鼠軌跡；輸入翻譯排除密碼框，不自動送出表單，無 GPS、支付或帳號註冊功能。

受支援的瀏覽器翻譯、OCR 與語義推理在裝置上執行。瀏覽器可能下載語言資源；Hugging Face 及其資源域名提供語義模型，可能取得 IP 等連線資料；網頁及查詢在本機推理，執行程式與 Wasm 隨擴充功能提供。

API 文字與認證 Key 直接傳給指定端點，營運者沒有中轉副本。PDF 傳送待譯段落，可附上目前頁最多約 20,000 字元與相鄰頁各最多約 1,200 字元的上下文，不將完整 PDF 當作翻譯附件。自動網頁翻譯預設關閉，啟用、授權及確認後可在側欄關閉時處理新開或重新整理的頁面。服務商可能計費、保留請求或在其他國家處理資料，適用其條款。

遠端 API 要求 HTTPS，同機 loopback 可使用 HTTP。線上 PDF 從使用者指定的 HTTP(S) 來源下載，省略請求憑證與來源引用，不攜帶翻譯 Key。HTTP 來源及重新導向沒有 HTTPS 傳輸保護；請優先用可信 HTTPS 來源，或下載後開啟本機檔案。

3. 儲存與安全

API 設定存於擴充功能 chrome.storage.local，PDF 資料與快取存於 IndexedDB，不使用瀏覽器同步。API 設定、PDF、檔名、原文、譯文及快取使用 AES-GCM 自動加密，無須密碼或重新啟動解鎖。不可透過 Web Crypto 匯出的隨機 CryptoKey 在同一擴充功能的瀏覽器儲存中，不是系統或硬體保險庫；完整瀏覽器資料被複製或裝置被控制時仍可能被解密。摘要 ID、頁碼、版本、快取時間及密文大小等索引可觀察。

閱讀資料預設長期保留到使用者刪除或清除。快取按 30 天有效期及 1,000 筆上限在存取時檢查清理，不保证到期立即擦除磁碟。自動翻譯暫存狀態使用工作階段儲存；網址列文字交接讀取後刪除，後續存取檢查短期限期。舊資料逐筆驗證加密副本再替換，不能保證擦除資料庫舊頁或備份。金鑰遺失或損壞無法由營運者恢復，也不自動覆寫舊密文；重新安裝會清除本機設定及閱讀資料，之後可重新匯入自己的原 PDF 或閱讀備份。

4. 選擇、刪除與匯出

開啟或匯入前選「僅本次閱讀」，檔案、原文與譯文僅留在該視窗，關閉後遺失，不寫入記錄或快取，不刪除已有記錄，仍使用目前翻譯服務。設定可清除 Key、快取及模型；刪除文件清除原件、記錄、頁面成果及關聯快取，無法歸屬的歷史快取按明確提示處理。清除本機 Key 不會撤銷服務商金鑰或收回已送出的請求。

主動匯出的閱讀包 ZIP 未加密，含完整 PDF、原文、已儲存譯文及排版資料，沒有 API Key 或本機加密金鑰。刪除擴充功能記錄不會刪除外部匯出包、裝置備份或服務商副本，需分別處理。複製分享需相應授權。

5. 告知與限制

API 使用前顯示接收方及傳送範圍；首次設定、更換服務或擴大至自動翻譯需相應確認。可在設定撤回以阻止新請求，不能保證取消服務方已收到的在途請求。僅使用有權處理的資料，不得向未經許可的第三方傳送國家秘密或受限制保密資料，無法確認時取消並諮詢所屬單位。機器翻譯及 OCR 可能有誤，重要內容核對原文。

6. 官網、回饋與聯絡

GitHub Pages 靜態官網在本機記住語言，不讀取擴充功能 Key、文件或剪貼簿，沒有營運者嵌入的追蹤、外部字型或第三方表單；托管方可能處理 IP 等存取資料。GitHub Issues 公開，郵件由收件方及郵件服務處理，請勿提供憑證、私人 PDF 或保密內容。各第三方有自己的隱私條款，營運者不能代為保證刪除。

隱私疑問或刪除主動提供的支援資料，請聯絡上述信箱。本機資料需自行在擴充功能／瀏覽器處理，營運者不能遠端讀取、恢復或刪除。處理方式實質變更時更新政策、商店披露及所需告知。本政策不免除適用法律義務。

Direct Translate privacy policy

Effective and updated: 4 October 2026 · Version 0.6.8
Applies to the Direct Translate browser extension and product website
Operator: TIANMENG (individually operated)
Privacy and support: hello@tianmengdesign.com

Local storage and network transmission are separate. API translation sends text directly to your chosen service. Session-only reading does not prevent API transmission. Reading-package exports include the entire original PDF and are unencrypted. Process only authorized material.

1. Purpose and Limited Use

The extension provides bilingual webpage/PDF reading, user-triggered input translation, passage search and local reading results. No extension account is required. The operator runs no translation relay, telemetry or advertising service. Use of data obtained through Chrome extension APIs adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements: data is used only for the disclosed reading, translation, search and saving features. It is not sold, transferred for unrelated purposes, or used for advertising, data brokerage, creditworthiness or lending. Browsing activity is not collected for unrelated purposes. The operator does not receive or manually inspect extension content. Specific information voluntarily supplied for support is used to address that feedback.

2. Data handled

The extension processes selected webpage content, selections, input text, PDFs, extracted/source text and translations; current URLs, titles, passages and feature status needed for reading, locating and avoiding stale results; service/language preferences, API endpoint/model/key, permissions/confirmation choices; reading position, text coordinates, caches and model resources. Selected content may contain identifying, communication, health or financial information, which the extension cannot reliably remove. It does not collect complete browsing history, record all keystrokes/mouse movements or automatically submit forms. Password fields are excluded from input translation. There is no GPS, payment or account-registration feature.

3. Local processing and external services

Supported browser translation, OCR and semantic inference process text on the device. Browsers may download language resources; semantic models are downloaded from Hugging Face and its resource domains, whose providers may receive connection metadata such as IP addresses. Passages and queries are used for local inference. Executable scripts and Wasm are bundled.

With API translation, text and any required authentication key go directly to the user-selected endpoint without an operator relay copy. PDF requests send target passages and may include context of up to about 20,000 characters from the current page and up to about 1,200 from each adjacent page. The original PDF is not uploaded as a translation attachment. Automatic webpage translation is off by default; opt-in, permission and applicable sending confirmation can enable processing of new/refreshed pages while the sidebar is closed. Providers may charge, retain requests or process data internationally under their own terms.

Remote APIs require HTTPS; same-device loopback services may use HTTP. Online PDFs are downloaded from user-selected HTTP(S) sources with request credentials and referrer omitted, without the translation key. HTTP sources and redirects lack HTTPS transmission protection. Prefer trusted HTTPS sources or download and open a local file.

4. Storage, retention and security

API settings use extension chrome.storage.local; PDF records and translation caches use extension IndexedDB, without browser sync. Version 0.6.8 automatically encrypts API settings, original PDFs, filenames, source text, translations and caches with AES-GCM, without password setup or restart unlocking. A random non-exportable Web Crypto CryptoKey is stored in the same extension's browser storage. This is not an operating-system or hardware vault: copying the complete browser profile or controlling the device may still allow decryption. IDs, page numbers, revisions, cache timestamps and ciphertext sizes remain observable.

PDF originals, extracted text, translations and reading position are saved by default until deleted or extension data is cleared. Translation caches are checked/cleaned on reads/writes against a 30-day validity and 1,000-entry limit; expiry does not guarantee immediate disk erasure. Temporary automatic-translation page state uses session storage. Short-lived address-bar text handoff is deleted on receipt and its expiry checked on later access. Migration verifies each encrypted replacement but cannot guarantee erasure of old database pages/backups. If the key is missing or damaged, the operator cannot recover records and the extension does not automatically create a replacement key to overwrite existing ciphertext. Reinstallation clears local settings/records; afterward you can import your own originals or reading backups. Keep your own copies.

5. Choices, deletion and export

Select session-only reading before opening/importing a PDF to keep that file and its source/translations only in the current window. Closing loses those results; no reading record or translation cache is written for that PDF. Existing records are kept and the selected translation service, including API sending, still applies. Settings allow clearing keys/caches/models. Deleting a document removes its original, metadata, saved pages and linked cache. Legacy unassigned caches are handled with an explicit prompt. Clearing a local key does not revoke the provider's key or recall sent requests.

User-initiated reading-package ZIP exports are unencrypted and include the entire original PDF, source text, saved translations and layout data, but no API key or local encryption key. Deleting extension records does not remove exported packages, device backups or provider-held copies; handle these separately. Copying/sharing requires appropriate authorization.

6. Sending confirmation and restrictions

The API notice identifies recipient and scope before use. First setup, recipient changes or extending to automatic translation require the applicable confirmation. Withdrawal in settings blocks new requests but cannot guarantee cancellation of requests already received by the provider. Process only authorized material; do not send state secrets or restricted confidential material to unauthorized third parties. If authorization is unclear, cancel and consult your organization. Machine translation and OCR may be wrong; check important content against the original.

7. Website, feedback and contact

The static GitHub Pages website stores a local language preference. It does not read extension keys/documents/clipboard or embed operator analytics, external fonts or third-party forms. Hosting providers may process access metadata. GitHub Issues are public; emails are processed by the recipient and email services. Do not submit credentials, private PDFs or confidential material. Share only necessary, redacted support information. Browser, hosting, model, API, email and feedback services have their own privacy terms; the operator cannot guarantee their deletion.

Contact the email above for privacy questions or deletion of support information you voluntarily sent. The operator cannot remotely read, restore or delete your device-local records; use the extension/browser controls. Material changes require updated policy/store disclosures and any necessary notices. This policy does not waive applicable legal obligations.
